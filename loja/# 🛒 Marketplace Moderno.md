# 🛒 Marketplace Moderno

Projeto de e-commerce front-end desenvolvido com HTML, CSS e JavaScript puro.

---

## 🚀 Funcionalidades

- Página inicial com produtos dinâmicos
- Sistema de carrinho com LocalStorage
- Página de checkout funcional
- Login e cadastro (UI)
- Dashboard admin simples
- Múltiplas categorias (Veículos, Eletrônicos, Móveis)
- Dark/Light mode
- Toast notifications
- Layout responsivo
- Animações modernas

---

## 🧠 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 🎯 Objetivo

Simular um marketplace moderno com múltiplas páginas, navegação real e experiência de compra funcional.

---

## 📸 Destaques

- UI moderna e responsiva
- Sistema de carrinho funcional
- Estrutura de e-commerce real
- Design adaptável para qualquer nicho
